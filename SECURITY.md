# Security Policy

## Supported Versions

Security updates are provided for the latest release on `master`.

| Version | Supported |
| --- | --- |
| Latest | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

Please report vulnerabilities privately using GitHub Security Advisories:

- [Report a vulnerability](https://github.com/yagna-1/drift-guard/security/advisories/new)

Please include:

- Vulnerability type and impact
- Affected files/components
- Reproduction steps or proof-of-concept
- Suggested mitigation (if available)

## Response Targets

- Initial acknowledgment: within 72 hours
- Triage decision: within 7 days
- Fix timeline: based on severity and exploitability

We will coordinate disclosure and credit reporters when appropriate.
